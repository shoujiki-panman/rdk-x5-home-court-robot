# StackChan Strider 裁判官のガワと木槌

M5Stack製品版スタックちゃん K151を載せた、とよふく式Strider用です。裁判官のガワは、顔の下に付ける法服の前身頃です。[参照したStriderの設計](https://github.com/Yeq6X/stackchan-strider/tree/852ae848d90ea7e85ada61842ec20ac88a86a82b)

| 部品 | データ | 大きさ |
| --- | --- | --- |
| 法服のガワ | [judge-robe.stl](judge-robe.stl) | 約66 × 22 × 9 mm |
| 飾りの木槌 | [judge-gavel.stl](judge-gavel.stl) | 約21 × 30 × 8 mm |
| 寸法を調整する場合 | [OpenSCAD原本](judge-strider.scad) | テープの厚さと差し込み穴のすきまを変更可能 |

両方ともSTLの向きで平置きし、PLA、0.4 mmノズル、積層0.2 mmを初回の設定にします。2部品のソリッド換算は約6.3 gです。テープの重さは別です。

1. 木槌をガワの表から差し込み、裏に出たピンを小片のテープで固定します。
2. 厚さ約0.55 mmの再剥離できる両面テープを、ガワ裏の曲面パッド2か所に貼ります。
3. 正面中央でガワの下端と固定ヨークの下端の高さをそろえて貼ります。電源を入れる前に取り付けを確認し、低速で前進と停止を試します。

STLが閉じた単一の形状であることと、公開CAD上で首・ターンテーブル・脚の動く範囲から離れていることを確認しました。実機への取り付けと歩行は試作時に確認します。
